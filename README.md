# SimpleInteractionsBTA
A mod for Minecraft's Better Than Adventure! fork which adds the ability to input/extract items from furnaces and trommels with left-click block interactions

Left-click a furnace or trommel with any processable item or fuel type in your hand and it'll add it straight into the correct slot.
Shift-left-click with an empty hand to take out the result from the output slot.
No more tedious GUI interactions!
